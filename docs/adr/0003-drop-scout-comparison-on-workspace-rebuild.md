# Drop Scout Comparison, the general leaderboard, and the old Insight profile when rebuilding Player Workspace

Ao reconstruir a página Player Workspace do zero (renomeada para Análise de Jogadores, em torno de uma nova visão de comparação single-player escopada por Position Group), decidimos remover do código o Scout Comparison, o leaderboard geral por Metric e o Insight baseado em regras — junto com os Reports em PDF de ambos — em vez de preservá-los. Consideramos mover essas features para uma página própria antes de zerar o Workspace, mas descartamos essa opção: o custo de manter esse código rodando sem um dono claro no novo design superava o benefício de não perder a funcionalidade. Se a necessidade voltar, essas capacidades são reconstruídas como tarefa nova, com o design que fizer sentido no contexto da época.
